DineXpert Restaurant App

Description:
DineXpert is a React Native mobile application that allows users to browse menus, place orders, and make reservations.

Features:
- Login system
- Menu with images
- Cart & Order system
- Order history
- QR Code reservation
- Dashboard & Logout

Installation:
1. Open Snack Expo
2. Paste App.js code
3. Install dependencies:
   - @react-navigation/native
   - @react-navigation/bottom-tabs
   - react-native-qrcode-svg
